## 詰まったところ

- 大きくは「form」タグの使い方がわからなかった。
- 「label」をどこにどのようにつけるのかがわからなかったため、前の章に戻って確認した。labelのすぐ後ろに入力するとform枠の前に表示され、後ろに記入すると後ろ側に表示されることが分かった。
- 「select」の使い方がわからず、前の章に戻った。selectは中にoptionタグを使って項目を作らなければならないことが分かった。
- 「textarea」の記入方法もわからず前に戻って確認した。textareaには同じかっこの中にrow(行数)とcols(横幅)を設定することを知った。
- 必ず回答してもらいたい項目にはタグの最後に「required」をつける必要があることが分かった。
- 送信ボタンは「butto type="submit"」で作れて、終了タグが必要。そして、「送信ボタン」という文字を表示するためにはlabelではなく開始タグと終了タグとの間に記入することを知った。

- ここで初めてGitHubの設定を行った。
- 順番に作っていたが、GitHubの画面内の表示項目が少し変わっていたようで、GoogleのAIにどれが設定すべきといわれている項目なのか聞いてしまった。
- また、英語を読めないため、日本語訳にしている弊害で見つけにくいことを知った。今後は翻訳機能を切り替えながら見ていこうと思う。

## 反省

- 「h1～h6」や「p」などはしっかり仕えたと思う。
- 「a」や「img」などはちょっとだけ考えた。
- 「form」は全然使えていなかったから、これからまた見返しながら使っていきたいと思う。
- GitHubについてはあまり理解できないままとりあえず書き写すように進めてしまった。エラーが出たらGoogleAIにスクリーンショットを送って検索をかけてしまったため、次からはエラー内容をほかで検索して、それでもわからないときに頼ろうと思う。また、最終的なコミットの仕方は解凍を見て行っている。次回からはもう少し自分で考えられるようになっていたいと思う。
